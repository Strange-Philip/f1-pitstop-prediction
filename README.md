# F1 Pit Stop Prediction

Kaggle Playground Series S6E5 — predicting F1 pit stop outcomes.

**Competition:** https://www.kaggle.com/competitions/playground-series-s6e5/data

## Project Structure

```
data/        # Raw and processed competition data
notebooks/   # EDA and experimentation
src/         # Reusable Python modules
outputs/     # Submission files, model artifacts, plots
```

## Setup

```bash
pip install -r requirements.txt
```
